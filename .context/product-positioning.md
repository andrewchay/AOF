# AOF 产品定位宣言（Product Positioning）

> 日期: 2026-08-07
> 状态: 初稿，待与创始人确认
> 目标客户: 中小企业（含小团队/一人公司起步、中型企业扩展）

---

## 一、一句话定位

> **AOF = 企业知识的 "Agent-Ready 资产化引擎"**
> 一次摄取企业过往所有内外知识，自动产出知识图谱、RAG 向量库、LLM Wiki / OKF、Agent 训练数据四种形态资产，让 AI Agent 开箱即懂、即调即用。

## 二、我们解决什么问题

企业知识散落在文档/SOP/API/数据库/网盘，传统 RAG 每次检索都临时拼凑、知识不沉淀；传统知识图谱重实施、非技术人员用不起来。

AOF 把"知识"变成**可持续演进、多形态表达、Agent 可消费的资产**，让小团队也能像大公司一样拥有一套知识操作系统（Agentic OS）的底座。

## 三、核心价值主张

| 维度 | AOF 承诺 |
|------|----------|
| **一次摄取，多形态产出** | 同一批源数据，自动生成图谱 + 向量库 + LLM Wiki/OKF + 训练数据 |
| **面向 Agent 设计** | 输出符合 OKF 规范、可被 MCP / A2A 编排的 Agent 直接消费 |
| **知识可演进** | Ingest → Query → Lint 闭环，知识库自愈式积累，不重复造轮子 |
| **轻量可落地** | 中小企业可私有化/本地部署，零运维起步，随规模平滑扩展 |
| **口径一致** | 同一指标/术语在不同资产中定义一致，降低 Agent 幻觉与分歧 |

## 四、目标客户分层

| 层级 | 特征 | 产品形态 | 收费 |
|------|------|---------|------|
| **小微/一人公司** | 1-5人，零运维、成本敏感 | 轻量版（本地/单机） | 订阅/按量 |
| **中小企业（主战场）** | 5-100人，要私有化+快落地 | 标准版（含企业级底座） | 按席位/私有化 |
| **中大型企业** | 100人+，多租户/审计/定制 | 企业版（对齐通用版 Agentic OS） | 定制实施 |

## 五、范围界定（做什么 / 不做什么）

**做什么：**
- 多源知识摄取与增量同步（现有）
- 四形态知识资产化产出（知识图谱/RAG/LLM Wiki-OKF/训练数据）
- Agent 可消费的知识接口（OKF 目录、MCP Server、渐进式披露 index.md）
- 企业级底座（RBAC/多租户/审计/缓存/限流熔断，现有）

**不做什么（MVP 阶段）：**
- 不重做通用 Agent 编排框架（复用 Dify/LangGraph 等生态）
- 不做领域 LLM 微调服务（仅提供训练数据生成）
- 不绑定单一模型厂商

## 六、差异化护城河

1. **LLM Wiki / OKF 落地**：当前 Dify/RAGFlow 均无完备的 OKF 输出，AOF 抢占标准窗口。
2. **四形态全打通**：竞品多只做 1-2 种形态，AOF 是"知识资产全家桶"。
3. **训练数据闭环**：直接产出 Agent 微调/评测数据，这是大多知识平台缺乏的。
4. **中小企业友好**：比企业级图谱厂商轻量、比开源 RAG 更"资产化"。
