P0–P6 的单域工程验收见 [验收台账](architecture/p0-p6-acceptance.md)，`test_finance_review_e2e.py` 验证本地查询→审批→工单/对账。以下部署门禁用于正式生产，不能倒过来将“没有大型基础设施”当作单域本地验收的阻塞。

适用范围：
- `/Users/chaihao/LLM/AOF/services/semantic_middle_layer_api`
- 中间层构建链路（ontology + mapping + regression + skills suggestions）

## 2. 构建前检查

- [ ] 一键预检通过：
  - `bash tools/ci/pre_release_check.sh`
- [ ] 治理门禁通过（无待审批变更单）：
  - `python tools/governance/validate_release_gate.py --root data/governance --strict`
  - （可选）按 topic 发布时：`python tools/governance/validate_release_gate.py --root data/governance --strict --topic <topic>`

- [ ] 关键脚本语法检查通过：
  - `bash -n tools/middle_layer/run_semantic_middle_layer.sh`
  - `bash -n services/semantic_middle_layer_api/run_api.sh`
- [ ] Python 编译检查通过：
  - `python -m py_compile services/semantic_middle_layer_api/app.py`
  - `python -m py_compile tools/middle_layer/build_semantic_middle_layer.py`
- [ ] OpenAPI 与实现端点一致（至少核心端点）：
  - legacy ingest/build/artifacts/export
  - semantic proposals/compiler/query/knowledge/ontology/reasoning
- [ ] 受治理 release 回归通过：
  - `python -m pytest -q tests/test_semantic_release_e2e.py`
- [ ] release 验证失败关闭：无效 principal、未批准 proposal、未批准 promotion、未知约束均不能成功

## 5. 发布后 5 分钟验收（Smoke Test）

- [ ] `GET /healthz` 返回 `{"status":"ok"}`
- [ ] 打开 `/docs` 可访问
- [ ] 调用链路最小闭环：
  1. `POST /v1/ingest/docs`
  2. `POST /v1/ingest/metadata`
  3. `POST /v1/build/topic`（可先 `skip_align=true`）
  4. `GET /v1/artifacts/{run_id}`
- [ ] 产物生成成功：manifest + mapping + regression
- [ ] `GET /v1/ops/trusted-runtime` 返回可用遥测
- [ ] 在非生产租户完成一次：签名 principal -> proposal -> validate -> approve -> compile -> publish -> query receipt
- [ ] 验证旧 `/v1/semantic/compile` 返回 `410`，不存在无治理 SQL 旁路
