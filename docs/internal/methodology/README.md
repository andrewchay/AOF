# AOF 方法论体系

本文档集合是 AOF（Agentic Ontology Factory）的内部方法规范，定义了本体抽提、质量控制和迭代优化的核心方法论。

## 核心原则

1. **反思驱动** - 每个阶段都要有复盘机制，持续改进
2. **迭代工作流** - 小步快跑，快速验证，及时调整
3. **质量控制** - 内置质量门，不合格不流转
4. **知识压缩** - 将经验沉淀为可复用的方法论
