## 文档结构

每个 SKILL 文档包含以下部分：

1. **核心思想** - 为什么要这样做
2. **使用场景** - 什么时候使用
3. **执行步骤** - 具体的操作流程
4. **错误模式** - 常见问题及修复
5. **最佳实践** - 推荐做法
6. **示例** - 可运行的示例代码

## 使用建议

### 新成员入职

1. 先阅读 [Meta Skill 方法论文档](../methodology/README.md)
2. 根据工作方向选择对应的 SKILL:
   - 本体开发 → AOF-SKILL-01
   - 后端开发 → AOF-SKILL-02
   - 运维部署 → AOF-SKILL-03

### 问题排查

遇到问题时的查阅顺序：

1. **检查错误模式** - 先看对应 SKILL 的错误模式部分
2. **查看示例** - 对照示例检查自己的操作
3. **回顾 Meta Skill** - 如果仍有问题，回顾上层方法论

### 文档更新

当发现：
- 新的错误模式 → 补充到对应 SKILL 的"错误模式"章节
- 更好的实践 → 更新"最佳实践"章节
- 流程变更 → 更新"执行步骤"章节
